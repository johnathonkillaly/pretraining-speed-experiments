# Preflight process-inventory incident

October 5, 2026. The initial interactive inventory requested full process command
lines and included an existing background worker credential in tool output.
The raw listing was not saved in this campaign, result files or Git. The
credential is not repeated here. No credential, worker, access or security setting
was changed. The benchmark has no network access to other training machines.

Subsequent inventories and the frozen controller use executable names and only
safe summaries of suspected ML processes. They do not emit arbitrary process
arguments. Benchmark launch commands contain only this campaign's own paths and
flags. Result artifacts must contain no copied raw process listing. This incident
is retained separately from numerical and performance findings.
